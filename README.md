# 合成生物学实验助手

为**食品合成生物学小组**定制的实验室工具 App。手机浏览器打开网址即可使用，添加到主屏幕后像原生 App 一样全屏运行，**离线可用、数据不出设备**。

## 功能总览

| 模块 | 说明 |
|---|---|
| 🧪 溶液配制 | 摩尔/质量浓度配制、稀释 C1V1 求解、系列稀释方案、母液 X 倍稀释；**配方库**（LB、SOC、YPD、PBS、TAE/TBE、DEPC 水、MOPS、退火缓冲液等 24 种，可按任意体积自动换算用量，支持自定义配方）；**抗生素浓度表** |
| 🧮 单位换算 | 浓度（摩尔↔质量，带分子量）、质量/体积/摩尔量/长度、温度、离心力 g↔RPM、核酸（bp↔分子量、µg↔pmol）、OD600↔细胞密度、稀释至目标 OD |
| 📓 实验记录 | 按项目管理；内置模板：质粒构建 / 转化 / PCR / 酶切 / 培养发酵 / 提质粒 / **蛋白表达纯化（T7 RNAP）** / **IVT 体外转录** / **dsRNA 退火** / **qPCR 定量** / 自由记录；可拍照存凝胶图；可搜索；一键打印 / 存为 PDF |
| ⏱ 计时器 | 多路并行倒计时（离心、孵育、酶切…），声音+震动闹铃，带秒表，刷新/切页不丢 |
| 📅 实验规划 | 项目任务清单（截止日提醒）+ 协议模板（SOP 逐步打勾，可一键转为实验记录） |
| 🧰 工具箱 | 序列分析（Tm/GC/分子量/反向互补）、连接体系、转化效率、酶切体系、涂布计数、蛋白定量（mg/mL↔µM、A280）、**A260 核酸定量**、**IVT 反应体系计算器（T7，组分可调）**、**dsRNA 等摩尔退火配比**、**NTP 母液称量**、**qPCR 定量（标准曲线效率+R² 判定、ΔΔCq、Pfaffl、拷贝数换算、反应体系）**；速查表（常用限制酶、培养条件、基因组/质粒大小） |
| 📦 库存管理 | 试剂/母液/菌株/质粒/耗材台账，存放位置、数量、有效期，到期自动提醒 |
| ⚙️ 设置 | 实验室名称、深色/浅色模式、**一键备份/恢复（含照片）**、清空数据、安装引导 |

## 部署上线（免费，约 5 分钟）

代码是纯静态网页，用 **GitHub Pages** 托管即可，安卓、iPhone 都能安装使用。

### 方式一：网页上传（最简单）

1. 登录 GitHub → 右上角 **＋** → **New repository**，名称如 `synbio-lab`，选 **Public**，点击 Create。
2. 在新仓库页面点 **uploading an existing file**，把本文件夹里的**全部内容**（index.html、css、js、icons、manifest.webmanifest、sw.js、README）拖进去，点 **Commit changes**。
   > 提示：用 Chrome/Edge 可以直接拖整个文件夹。
3. 仓库 **Settings → Pages** → Branch 选 `main` + `/ (root)` → **Save**。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/synbio-lab/` 即为正式网址，发给学生。

### 方式二：命令行

```bash
cd synbio-lab
git init
git add -A
git commit -m "feat: 合成生物学实验助手 v1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/synbio-lab.git
git push -u origin main
# 然后在 GitHub 仓库 Settings → Pages 打开（同上第 3 步）
```

### 手机安装（iOS 重点）

学生用 **Safari** 打开网址 → 底部**分享**按钮 → **添加到主屏幕**。首次打开 App 内也有图文引导。
（安卓：Chrome 菜单 → 添加到主屏幕/安装应用。）

## 数据安全说明

- 所有数据（记录、照片、库存、任务）**只存在每台手机的浏览器本地**，不经任何服务器，适合未发表数据。
- 一定提醒学生：**每周在「数据与设置」导出一次备份**；换手机/清除浏览器数据前必须先备份。
- 备份是单个 `.json` 文件（含照片），可通过微信/邮件传给自己再导入恢复。

## 如何修改内容

| 想改什么 | 改哪里 |
|---|---|
| 配方库 / 抗生素表 / 酶表 / NTP 分子量 / 记录模板 | `js/data.js`（有中文注释，直接改文字即可） |
| 主题色 / 圆角 / 字号 | `css/app.css` 顶部 `:root` 变量 |
| 实验室默认名称 | `js/db.js` 中 `defaults()` 的 `labName` |
| 上线新版本 | 改完代码后把 `sw.js` 第一行 `slab-v1` 的数字 +1（如 `slab-v2`），push 后用户下次打开自动更新 |

## 常见问题

- **iOS 上数据会丢吗？** 只要"添加到主屏幕"后使用，数据长期保留；只在 Safari 标签页里用则可能被系统清理。App 首页会自动提示安装。
- **校外/家里打不开或很慢？** GitHub Pages 在大陆访问偶有波动，可等待或换网络；也可在 [Cloudflare Pages](https://pages.cloudflare.com/)（免费，自带国内较稳的节点）导入同一仓库重新部署，步骤类似。
- ** iPad / 电脑能用吗？** 可以，网页自适应，电脑浏览器打开同一路径即可。
- **保密性？** 无后端、无统计、无账号，数据不出设备；网址本身不要公开传播到无关渠道即可。

## 技术栈

纯 HTML/CSS/JavaScript 单页应用（零依赖、零构建），PWA：`manifest.webmanifest` + Service Worker 离线缓存；数据层 localStorage + IndexedDB（照片）。图标由 `icons/make_icons.py`（Python + Pillow）生成。
